# Rotá — Dale una nueva vida a lo que ya no utilizás

## Descripción del proyecto

Rotá es una aplicación móvil orientada a promover la reutilización mediante la donación gratuita de artículos de distintas categorías. Permite a las personas publicar objetos que ya no necesitan y conectar con otros usuarios de su comunidad o zonas cercanas que puedan darles una segunda vida, facilitando la coordinación de entregas en puntos acordados.
